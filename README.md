# ISO 400 — portafolio personal

Copia independiente de la web de The Sign Studio para desarrollar la identidad visual y el look and feel de ISO 400. Conserva inicialmente los 11 proyectos, todos los textos, imágenes, videos y funciones de la web.

Este repositorio es privado y no tiene publicación web configurada. Las actualizaciones de ISO 400 no deben enviarse a nicolirat/TSS.
